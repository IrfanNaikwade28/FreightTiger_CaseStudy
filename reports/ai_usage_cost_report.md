## Optional Groq explanation layer (`--llm`)

The pipeline now ships a **Groq-only** optional layer (`src/llm_explainer.py`) that may rewrite the free-text `reason` cell of **flagged + evidence-justified** rows only (at most 3 rows on the supplied data). Hard guardrails:

- Flags, baselines, +20% threshold, numbers, and `matched_note_id` are computed entirely by the deterministic modules; the LLM never sees shipment data and cannot change any of them.
- The LLM is invoked only after the deterministic pipeline has already validated route, date window, and cost impact; the prompt contains only the route, week, both percentage comparisons, and the deterministic explanation text.
- Output must be single-line, ≤600 chars, and cite the matched note id; anything else (HTTP failure, empty/overlong/ungrounded text) falls back to the deterministic explanation.
- Offline by default; online only with `--llm` **and** `FREIGHTTIGER_LLM_API_KEY`. Bounded by `--llm-max-calls` (default 20). Temperature 0.

Configuration (environment):

| Variable | Purpose | Default |
|---|---|---|
| `FREIGHTTIGER_LLM_API_KEY` | Groq API key (never committed) | unset → offline |
| `FREIGHTTIGER_LLM_BASE_URL` | Chat-completions base | `https://api.groq.com/openai/v1` |
| `FREIGHTTIGER_LLM_MODEL` | Groq model id | `qwen/qwen3.8-27b` |

Transport is stdlib `urllib.request` (no third-party SDK). When online, the console summary reports **measured** `prompt_tokens` / `completion_tokens` from Groq's `usage` metadata; estimated cost is computed only if the model is in the local published-price table (currently `qwen/qwen3.8-27b` $0.80/$4.00 per 1M in/out, `openai/gpt-oss-120b`, `openai/gpt-oss-20b` — verify at console.groq.com/docs/models before relying on estimates), otherwise cost prints as unknown. Missing `usage` metadata is counted explicitly, never back-filled.

## What remains fully deterministic

Retrieval, note matching, baselines, anomaly flags, verdicts, and all CSV numeric fields are pure standard-library Python with no randomness and no clock dependence. The LLM layer is an optional, instrumented paraphraser of already-validated evidence text — a guardrail-first design, since a confidently wrong justification scores worse than "could not find one."
